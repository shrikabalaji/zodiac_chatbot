# LIBA Day 2 — Start Here

## Today’s outcome

Each team will run a six-agent system locally, trace how evidence moves between agents, replace the six default agent instruction files with its own Day 1 work, compare the before/after behavior, and prototype a small learning game in Lovable.

## Files in this student pack

- [`STUDENT_QUICKSTART.md`](STUDENT_QUICKSTART.md) — exact install, launch, replacement, and evidence steps.
- [`LANGCHAIN_CODE_MAP.md`](LANGCHAIN_CODE_MAP.md) — the small set of functions to understand.
- [`QUIZ_STUDENT_SHEET.md`](QUIZ_STUDENT_SHEET.md) — opening and closing quizzes without answers.
- [`LOVABLE_GAME_CHALLENGE.md`](LOVABLE_GAME_CHALLENGE.md) — the game brief and copyable build prompt.

The facilitator runbook, quiz answers, and game instructions are distributed separately.

## One-day evidence target

Every team should finish with:

1. a screenshot of the baseline six-agent run;
2. the six replaced Markdown agent files;
3. a screenshot of the same scenario after replacement;
4. three written observations explaining what changed and what did not;
5. a working Lovable game link or a screenshot plus the final prompt; and
6. a one-sentence human-approval boundary.

Use fictional or sanitized scenario data. Never place credentials or personal data in the repo, agent files, screenshots, or submissions.
