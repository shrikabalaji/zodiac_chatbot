# The six replaceable agent files

These six Markdown files are the easiest part of the system to customize. The app reads them when an agent runs, so save the files and start a **new run** to observe the change.

| App agent | File students must replace |
|---|---|
| Analytics / PRISM | `01-analytics-agent.md` |
| Marketing / PULSE | `02-marketing-agent.md` |
| HR / NOVA | `03-hr-agent.md` |
| Operations / ATLAS | `04-operations-agent.md` |
| Finance / LEDGER | `05-finance-agent.md` |
| General Management / JARVIS | `06-general-management-agent.md` |

## Safe replacement method

1. Keep the filenames exactly as shown.
2. Paste today's agent instructions into the matching file.
3. Preserve the Markdown format; plain text is also accepted.
4. Do not paste API keys, personal data, or hidden credentials into these files.
5. Run the same scenario before and after the replacement.
6. Compare the language, priorities, evidence, and hand-offs. The calculation tools and safety rules remain unchanged.

If a file is missing or empty, the app stops with an exact error instead of silently using the wrong prompt.
